# Fit Tracker

A simple weight and exercise tracker. React + Vite + TypeScript, data stored in the browser's `localStorage` (no backend).

## Features

- Quick weight entry with a line chart (7/30/90-day and all-time ranges)
- Exercise logging from a menu of common exercises, with rep counting in +1/+5/+10 increments and added weight in lbs

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deploys as a static site — works out of the box on Vercel with the default Vite preset (build command `npm run build`, output directory `dist`).
